# Django Cards API

A simple REST-style API built with Django to manage Pokémon cards.

## 🚀 Features
- List all cards
- Retrieve a card by ID
- Filter cards by grade (e.g. `/cards/?grade=10`)
- SQLite database
- JSON responses

## 🛠 Tech Stack
- Python
- Django
- SQLite
